# Contract: 자세 체험 화면·안내

**Status**: 사용자 확정 행동을 표현하는 AI 화면/대본 초안. 문구·배치·연출 강도는 사용자 확정 사항과 구분한다. 실제 음성 파일은 아직 준비하지 않았다.

## 확정 행동

제자리에서 실제로 숙인다. 서서 준비 완료를 선택한 순간을 기준으로 삼는다. 낮은 자세 연속 2초면 버튼 없이 인정하고 일어서도 된다고 알린다. 연습 중 연기층 높이는 일정하고 움직임은 유지한다. 성공 보상으로 연기를 없애지 않는다. 원리 설명은 시야 확보보다 연기 흡입 감소가 중심이다.

## 화면별 입력·출력

| 상태 | 표시/음성 초안 | 입력과 전이 |
|---|---|---|
| 메뉴 | 연기 속에서 자세 낮추기 — 제자리에서 몸을 낮추는 이유와 자세 연습 | 콘텐츠 선택. 후보 전체를 구현 완료처럼 노출하지 않음 |
| AwaitingReady | 편하게 서 주세요. 주변에 몸을 숙일 공간이 있는지 확인한 뒤 ‘준비 완료’를 선택하세요. 불편하면 언제든 중단할 수 있습니다. | 준비 완료/메뉴. 유효 추적과 새 버튼 선택 필요 |
| PrincipleGuidance | 뜨거운 연기는 위로 올라가 천장 부근에 모입니다. 연기 흡입을 줄이기 위해 머리와 몸을 낮춥니다. | 초기 연기 상승·축적 관찰. 안내 완료 후 연습 |
| Practice 대기 | 이동하지 않고, 무리하지 않는 범위에서 머리와 몸을 낮춰 보세요. | 실제 자세만 판정. 추가 선택/이동 요구 없음 |
| 낮은 자세 인식 | 낮은 자세가 인식됐어요. 잠시 유지해 주세요. | 연속 2초 자동 판정, 버튼 없음 |
| 인정 전 일어섬 | 자세 확인이 이어지지 않았어요. 불편하지 않다면 다시 낮춰 보세요. | 시간 0. 기다려도 실패/처벌 없음 |
| 완료 인정 | 자세 연습을 마쳤어요. 이제 편하게 일어서세요. | 즉시 안내, 완료 한 번 고정 |
| CompletionGuidance | 이번 체험은 제자리 자세 연습입니다. 연기는 아래쪽까지 퍼질 수 있고, 몸을 낮추는 것만으로 안전해지지는 않습니다. 실제 화재에서 대피가 가능한 경우에는 연기를 피해 낮은 자세로 신속히 이동해야 합니다. | 필수 한계 안내 후 Result |
| Result | 연기 속에서 자세 낮추기 / 자세 연습 완료 / 연기가 모이는 모습 관찰 · 몸 낮추기 연습 | 다시 체험하기/콘텐츠 선택으로 |

‘잠시 유지’는 내부 2초 인식 조건이다. 사용자에게 실제 화재에서 2초 버티면 안전하다는 의미의 카운트다운/등급/생존 수치를 보여주지 않는다. 기록은 실제 제공한 관찰과 연습만 표시한다. 탈출 완료·안전 확보·전신 자세 합격이라고 표시하지 않는다.

## 중단·오류

| 조건 | 표현/행동 |
|---|---|
| 모달 열림 | 기존 계속하기/설정/처음부터 다시/콘텐츠 선택으로. 뒤의 판정·음성·연기 정지 |
| 머리 위치 추적 불가 | 위치를 확인할 수 없어 연습을 잠시 멈췄습니다. 추적이 돌아오면 다시 안내합니다. 메뉴로 나가기 가능 |
| 기준 공간 변경 | 시작 높이를 다시 확인해야 합니다. 편하게 서서 준비 완료를 선택해 주세요. 자동 재보정 금지 |
| 안내 파일/필수 참조 누락 | 체험을 시작할 수 없습니다. 콘텐츠 선택으로 돌아가 주세요. 완료 처리 금지 |
| 숙이기 불편/미인식 | 중단 경로 유지. ‘더 깊이’ 반복 압박이나 강제 자세 유지 없음 |

오류 안내는 성공과 구별되는 문구로 표시하고 색만으로 구분하지 않는다. pause/추적 복구는 완료를 새로 만들지 않는다. 재진입은 항상 새 준비부터다.

## 공간 표현

원리 관찰에서 연기가 위로 올라가 모이는 모습을 보여주고 Practice에서 층 경계를 고정한다. 입자 움직임은 계속되며 30초 대기/반복 숙임에도 층이 내려오지 않는다. 완료 안내 때도 연기를 유지하고 메뉴 이탈 때 정리한다. 층 경계는 카메라를 따라 움직이지 않는다.

낮은 위치를 초록색 안전 영역이나 맑은 공기 보장 구역으로 칠하지 않는다. 숙임에 따라 화면 fog를 지우거나 안전 게이지를 채우지 않는다. 연기는 단순화된 교육 연출이며 유해가스 농도 시뮬레이션이 아니다.

## 읽기·입력·음성

기존 Theme/한국어 폰트/버튼 상태와 World Space uGUI·XR 레이/트리거를 재사용한다. 새 Canvas 추적과 등록은 명시적으로 연결한다. 안내·중단은 서기/숙이기 모두 읽고 누를 수 있게 하고, 화면 배치를 위해 사용자의 카메라를 움직이지 않는다. 연습 중 별도 버튼 조작은 필요 없다.

필수 한국어 음성과 자막의 의미·순서를 일치시킨다. 자막 기본 켬, 기존 설정의 끄기/글자 확대를 존중한다. 필수 조작·추적 상태 문구는 자막 설정과 별개다. 소리를 꺼도 인식 상태와 완료를 읽을 수 있게 한다. 일반 pause는 음성·자막을 같은 지점에 유지한다.
