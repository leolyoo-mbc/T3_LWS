# Feature Specification: 자막 가독성과 표시 흐름 개선

**Feature Branch**: `main` (명세 작성 시점의 브랜치, 별도 브랜치 생성 없음)

**Created**: 2026-11-18

**Status**: Draft

**Input**: 사용자 대화에서 확정한 수정: 자막을 앞쪽 1m에 배치하고 보이는 크기를 유지한다. 자막 배경을 없애고 흰 글자와 검정 외곽선으로 표시한다. 음성 안내 중에는 일반 행동 안내를 숨기고, 긴 자막은 음성에 맞춰 짧게 나누며, 음성이 끝나면 행동 안내를 다시 표시한다. 필수 경고는 유지한다.

## Clarifications

### Session 2026-11-18

**→ Q:** 음성 자막이 나오는 도중 필수 경고가 생기면, 자막을 잠시 숨기고 경고만 보여줄까? → **A:** 경고만 표시한다. 일반 행동 안내와 음성 자막은 숨기고, 경고 해제 후 현재 진행에 맞는 자막이나 행동 안내를 복원한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 배경판 없이 가까운 자막 읽기 (Priority: P1)

학습자는 화재 상황을 관찰하면서 화면 아래쪽의 흰 자막을 읽는다. 자막 뒤의 배경판은 공간을 가리지 않고, 검정 외곽선이 글자와 주변 장면을 구분한다.

**Why this priority**: 사용자가 처음 보고한 문제는 오브젝트에 파묻히는 자막이며, 가까운 배치와 배경 제거를 선택했다. 읽기와 공간 관찰을 함께 유지해야 한다.

**Independent Test**: 세 콘텐츠에서 안내를 재생하고, 밝은 벽/불/어두운 복도를 배경으로 일반 크기와 150% 글자를 비교한다. 배치와 읽기는 실제 VR 기기에서도 확인한다.

**Acceptance Scenarios**:

1. **Given** 기존 자막 배치가 기록되어 있을 때, **When** 변경된 자막을 표시하면, **Then** 안정된 정면 기준으로 머리 앞쪽 1.0m에 배치되고 기존과 같은 시야상 크기와 아래쪽 위치를 유지한다.
2. **Given** 자막이 표시 중일 때, **When** 학습자가 주변을 관찰하면, **Then** 흰 글자와 검정 외곽선만 보이고 자막 뒤의 불투명 또는 반투명 배경판은 보이지 않는다.
3. **Given** 밝거나 어두운 대표 장면일 때, **When** 일반/150% 글자로 자막을 읽으면, **Then** 전체 문구를 식별할 수 있고 글자나 외곽선이 잘리지 않는다.
4. **Given** 메뉴/설정/결과/바닥 선택 버튼일 때, **When** 해당 화면을 열면, **Then** 자막 수정 때문에 기존 배경, 글자 스타일, 거리나 조작 영역이 바뀌지 않는다.

---

### User Story 2 - 중복 안내 없이 한 번에 하나의 일반 안내 읽기 (Priority: P1)

학습자는 음성이 재생되는 동안 음성 자막을 읽고, 음성이 끝나면 다음 행동 안내를 읽는다. 비슷하거나 같은 내용을 위아래에서 동시에 읽지 않는다.

**Why this priority**: 사용자가 같은 내용의 위아래 중복을 보고했으며, 일반 행동 안내와 음성 자막의 표시 시점을 나누는 방식에 동의했다.

**Independent Test**: 준비/설명/행동 대기 구간을 재생해 음성 안내 전후의 표시를 비교하고, 자막 끄기와 추적 오류를 별도로 확인한다.

**Acceptance Scenarios**:

1. **Given** 일반 행동 안내가 표시 중일 때, **When** 표시 가능한 자막이 있는 음성 안내가 시작되면, **Then** 일반 행동 안내는 숨겨지고 현재 음성 자막만 표시된다.
2. **Given** 음성 안내에 문장 사이의 짧은 무자막 구간이 있을 때, **When** 다음 자막을 기다리면, **Then** 일반 행동 안내가 그 사이에 잠깐 나타나지 않는다.
3. **Given** 음성 안내가 끝났거나 취소되었을 때, **When** 같은 콘텐츠의 행동 대기 상태가 유지되면, **Then** 그 시점에 유효한 행동 안내가 다시 표시된다. 콘텐츠를 나간 경우 이전 안내를 복원하지 않는다.
4. **Given** 자막 설정이 꺼져 있을 때, **When** 음성이 재생되면, **Then** 자막은 표시되지 않고 필요한 행동 안내와 필수 경고는 유지된다.
5. **Given** 추적 오류 또는 진행을 막는 오류가 발생했을 때, **When** 음성 안내 중이라도, **Then** 일반 행동 안내와 음성 자막을 숨기고 복구/중단에 필요한 경고만 표시한다. 경고가 해제되면 현재 음성 진행에 해당하는 자막을 표시하거나, 음성이 끝났다면 현재 유효한 행동 안내를 표시한다.

---

### User Story 3 - 말하는 부분만 순서대로 읽기 (Priority: P2)

학습자는 긴 설명 전체를 한꺼번에 읽지 않고, 현재 말하는 문장 또는 의미 단위를 순서대로 읽는다.

**Why this priority**: 여러 문장을 하나의 자막으로 표시하는 데이터가 확인되었으며, 사용자가 긴 자막의 분할에 동의했다.

**Independent Test**: 세 콘텐츠의 전체 음성 안내를 재생하고 자막 교체 시점, 누락, 순서, 줄 수를 확인한다.

**Acceptance Scenarios**:

1. **Given** 여러 문장으로 된 음성 안내일 때, **When** 음성이 순서대로 재생되면, **Then** 현재 말하는 문장 또는 짧은 의미 단위만 표시되고 뒤에 말할 문장 전체가 미리 나타나지 않는다.
2. **Given** 한 문장이 길 때, **When** 일반/150% 글자에서 두 줄을 넘게 되면, **Then** 의미 단위로 더 나누어 순차 표시하며 글자를 자동 축소하거나 내용을 잘라내지 않는다.
3. **Given** 분할된 안내일 때, **When** 처음부터 끝까지 들으면, **Then** 기존 음성과 자막 원문의 의미, 문구, 순서가 보존되고 각 자막은 해당 발화에 맞춰 교체된다.
4. **Given** 일시정지 후 재개 또는 콘텐츠 전환일 때, **When** 안내가 이어지거나 새로 시작되면, **Then** 자막도 같은 위치에서 이어지거나 새 안내로 바뀌며 이전 자막이 남지 않는다.

### Edge Cases

**→ 자막이 비어 있거나 꺼진 상태:** 배경판이나 빈 자막 영역이 남지 않으며 행동 안내와 경고를 읽을 수 있다.

**→ 경고와 일반 안내가 동시에 존재:** 필수 경고가 일반 행동 안내와 음성 자막보다 우선한다. 경고가 표시되는 동안 두 안내를 숨기며, 자막 설정이 꺼져 있어도 경고는 표시한다.

**→ 경고 해제:** 현재 콘텐츠와 음성 진행 상태를 기준으로 복원한다. 경고 때문에 놓친 이전 자막을 몰아서 표시하거나 완료된 안내를 다시 표시하지 않는다. 기존 음성의 중단/재개 규칙은 유지한다.

**→ 머리 회전/숙이기/순간이동:** 기존 추종과 재정렬 방식을 유지한다. 1m는 안정된 정면 기준 앞쪽 거리이며 매 순간 머리에 붙어 즉시 이동한다는 뜻이 아니다.

**→ 음성 완료 직후 다른 안내 시작:** 이전 단계의 행동 안내나 자막이 잠깐 복원되지 않는다.

**→ 자막보다 가까운 오브젝트:** 1m로 옮겨도 가려짐은 발생할 수 있다. 이번 명세는 모든 거리에서 가림을 없앤다고 보장하지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

**→ FR-001:** 현재 구현된 세 콘텐츠의 공용 음성 자막에 동일한 표시 규칙을 적용해야 한다.

**→ FR-002:** 자막은 안정된 정면 기준 머리 앞쪽 1.0m에 배치해야 한다. 기존 1.8m 배치와 비교해 시야상 글자 크기, 자막 영역 크기와 아래쪽 배치 각도를 유지하고 기존 150% 글자 확대를 보존해야 한다.

**→ FR-003:** 음성 자막은 배경판 없이 흰 글자와 검정 외곽선으로 표시해야 한다. 자막이 없어지면 자막 전용 시각 요소도 사라져야 한다.

**→ FR-004:** 다른 화면과 환경 글자의 스타일/배치/배경을 변경하지 않아야 한다. 자막 전용 표시 변경으로 메뉴, 설정, 결과, 선택 버튼과 일반 행동 안내의 디자인을 함께 바꾸지 않아야 한다.

**→ FR-005:** 자막이 켜진 음성 안내 중에는 일반 행동 안내를 숨기고, 문장 사이의 무자막 간격에도 숨김을 유지해야 한다. 안내가 끝나면 현재 상태의 유효한 행동 안내를 복원해야 한다.

**→ FR-006:** 자막이 꺼져 있을 때는 일반 행동 안내를 음성 재생만을 이유로 숨기지 않아야 한다. 추적/구성/전환 오류와 복구 또는 중단에 필요한 필수 경고는 자막 설정이나 음성 재생 여부와 관계없이 표시해야 한다. 필수 경고 표시 중에는 일반 행동 안내와 음성 자막을 모두 숨겨야 한다. 경고가 해제되면 현재 콘텐츠와 음성 진행 상태에 맞는 자막 또는 유효한 행동 안내를 복원하며, 자막이 꺼져 있으면 자막을 복원하지 않아야 한다. 지난 자막을 재표시하거나 기존 음성 중단/재개 규칙을 변경하지 않아야 한다.

**→ FR-007:** 위아래 동일 문장 중복을 재현할 수 있는 구간을 조사하고, 같은 일반 안내가 동시에 두 번 표시되지 않게 해야 한다. 현재의 상태 안내와 자막 동시 표시를 원인 후보로 취급하되 보고된 중복의 유일한 원인으로 단정하지 않아야 한다.

**→ FR-008:** 자막은 한 번에 한 문장 또는 짧은 의미 단위로 표시해야 한다. 일반/150% 글자에서 최대 두 줄을 기본 제한으로 삼고, 긴 문장은 의미 단위로 추가 분할해야 한다. 여러 완결 문장을 한 자막에 누적하지 않아야 한다.

**→ FR-009:** 기존 음성과 전체 자막 원문은 유지하고 표시 구간과 시점만 조정해야 한다. 분할로 문구가 누락/중복되거나 순서가 바뀌지 않아야 하며 음성보다 앞선 다음 설명을 미리 표시하지 않아야 한다.

**→ FR-010:** 일시정지/재개, 다시하기, 메뉴 복귀와 콘텐츠 전환에서 자막과 음성의 진행을 일치시키고 이전 안내가 남거나 잘못 복원되지 않게 해야 한다.

**→ FR-011:** 밝은 벽, 불, 어두운 복도에서 일반/150% 글자를 확인해야 한다. 외곽선만으로 읽기 어려운 경우 자동으로 배경을 복원하지 말고 해당 장면과 한계를 기록해야 한다.

**→ FR-012:** 구현 후 검증은 프로젝트 헌법의 실행 영상, 게임 소리 분리, 화질과 보관 기준을 따라야 한다. 기기 확인과 Editor 확인을 구분하고 실제 음성을 듣지 않았으면 자막 타이밍 청취 검증을 완료했다고 보고하지 않아야 한다.

### Key Entities

**→ 음성 안내:** 기존 음성, 전체 대사와 재생 상태를 가진 교육 안내.

**→ 자막 구간:** 음성 안내의 일부 문구와 그 문구를 표시하는 시작/종료 시점. 전체 구간을 합치면 기존 대사가 보존된다.

**→ 일반 행동 안내:** 현재 단계에서 학습자가 해야 할 행동. 음성 자막과 표시 시점을 나누며 단계가 바뀌면 새 안내를 따른다.

**→ 필수 경고:** 추적 또는 진행 오류와 복구/중단에 필요한 정보. 일반 행동 안내와 음성 자막보다 우선하며, 표시 중에는 두 안내를 숨긴다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

**→ SC-001:** 세 콘텐츠에서 안정된 정면 기준 자막 앞쪽 거리가 1.00m ± 0.02m이고, 기존 배치와 비교한 시야상 글자 크기와 아래쪽 배치 각도의 차이는 각각 5% 이내다.

**→ SC-002:** 전체 안내 재생에서 자막 배경판 표시와 동일 일반 안내의 위아래 동시 중복이 각각 0건이다. 일반 행동 안내는 음성 안내 종료 후 복원되고 문장 사이에 깜박이지 않는다.

**→ SC-003:** 전체 자막 구간이 일반/150% 글자에서 최대 두 줄로 표시되고, 글자 잘림, 원문 누락, 원문 중복과 순서 오류가 각각 0건이다.

**→ SC-004:** 전체 음성 안내를 실제 재생해 들으며 확인했을 때 각 표시 구간이 해당 발화와 일치한다. 현재 구간과 관계없는 다음 문장 전체의 선행 표시가 0건이다.

**→ SC-005:** 밝은 벽/불/어두운 복도의 세 조건과 일반/150%의 두 크기 조합 모두에서 대표 자막 전체 문구가 식별 가능하고 외곽선이 잘리지 않는다. Quest에서 확인하지 않은 조합은 미검증으로 기록한다.

**→ SC-006:** 자막 끄기, 필수 경고, 일시정지/재개, 다시하기, 메뉴 복귀와 콘텐츠 전환 시나리오에서 필수 정보 누락과 이전 자막 잔류가 각각 0건이다. 필수 경고와 일반 행동 안내 또는 음성 자막의 동시 표시가 0건이고, 경고 해제 후 지난 자막의 재표시와 꺼진 자막의 복원이 각각 0건이다.

## Assumptions

**→ 사용자 확정:** 앞쪽 거리 1m, 기존과 같은 보이는 크기, 자막 배경 제거, 흰 글자와 검정 외곽선, 음성 중 일반 안내 숨김, 음성 종료 후 행동 안내 복원, 필수 경고만 우선 표시하고 해제 후 현재 진행에 맞게 복원, 긴 자막의 음성 연동 분할.

**→ 기본값:** 한 번에 최대 두 줄을 적용하고 글자 수 고정 제한 대신 실제 표시 결과로 분할 여부를 판단한다. 음성/대사 재작성과 재녹음은 포함하지 않는다. 추가 그림자는 기본 범위에 넣지 않는다.

**→ 미확정 및 제외:** 오브젝트 위 강제 표시, 장애물 회피, 사용자 거리 조절 기능은 이번 범위에 포함하지 않는다. 1m 배치만으로 모든 가림이 해결된다고 취급하지 않는다.
