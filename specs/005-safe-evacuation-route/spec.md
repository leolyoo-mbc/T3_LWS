# Feature Specification: 안전한 대피 경로 판단

**Feature Branch**: 기존 `main` 유지 — 브랜치 생성 훅 없음

**Feature Directory**: `specs/005-safe-evacuation-route`

**Created**: 2026-11-13

**Status**: Draft — 대화에서 확정한 요구를 문서화했으며, 별도 표기한 가정은 사용자 확정 사항이 아니다.

**Input**: 세 번째 독립 VR 콘텐츠로 ‘안전한 대피 경로 판단’을 제작한다. 학교 복도에서 계단·엘리베이터의 이용 여부를 판단하고, 연기로 막힌 계단을 피해 다른 비상계단으로 우회한다. 첫 번째는 안내 연습, 두 번째는 같은 학교의 다른 구역에서 스스로 적용하는 상황이다. 복도에서는 정해진 텔레포트 앵커로 이동하고, 확인 지점에서는 공용 UI의 선택지로 판단한다. 이용 가능한 계단을 바로 찾았으면 완료이며 막힌 계단 방문을 강제하지 않는다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 안내를 받으며 대피 경로 선택하기 (Priority: P1)

체험자는 학교 복도에서 유도표지와 계단 상태를 살펴보는 방법을 안내받고, 엘리베이터 대신 이용 가능한 비상계단을 선택한다.

**Why this priority**: 계단이라는 이름만 외우지 않고, 주변 상태를 확인한 뒤 대피 경로를 선택하는 기본 연습이다.

**Independent Test**: 첫 번째 상황만 실행해 엘리베이터 이용 시도와 계단 선택을 각각 시험한다.

**Acceptance Scenarios**:

1. **Given** 콘텐츠 선택 메뉴, **When** 이 콘텐츠에 진입하면, **Then** 학교 복도와 경로 확인·이동·선택 방법을 안내받는다.
2. **Given** 계단 앞 확인 지점, **When** 도착하면, **Then** 계단 상태를 볼 수 있고 ‘이 계단으로 대피한다 / 다른 경로를 찾는다’가 표시된다.
3. **Given** 이용 가능한 계단의 확인 지점, **When** 대피를 선택하면, **Then** 해당 상황의 경로 선택 연습이 완료된다.
4. **Given** 엘리베이터 앞 확인 지점, **When** ‘이용한다’를 선택하면, **Then** 탑승은 실행되지 않고 화재 시 엘리베이터를 이용하지 않는 이유를 안내받은 뒤 다시 판단할 수 있다.
5. **Given** 엘리베이터 앞 확인 지점, **When** ‘다른 경로를 찾는다’를 선택하면, **Then** 복도 이동을 계속해 계단을 찾을 수 있다.

---

### User Story 2 - 다른 구역에서 경로 상태를 보고 선택하기 (Priority: P1)

체험자는 배치가 다른 학교 구역에서 정답을 미리 안내받지 않고 이용 가능한 계단을 찾는다. 연기로 막힌 계단을 먼저 발견했다면 물러나 반대편 계단으로 우회한다.

**Why this priority**: 첫 상황의 방향·이동 순서를 외우는 대신 새 배치에서 판단을 적용하는 핵심 체험이다.

**Independent Test**: 두 번째 상황을 실행해 직접 대피 경로를 찾는 경우, 막힌 계단에서 우회하는 경우, 위험한 선택 후 다시 판단하는 경우를 각각 확인한다.

**Acceptance Scenarios**:

1. **Given** 두 번째 상황 진입, **When** 주변을 살피면, **Then** 첫 상황과 출발 위치·계단 방향·엘리베이터 위치가 다르고 한 계단은 연기로 막혀 있으며 다른 계단까지의 복도와 해당 계단은 이용 가능한 상태다.
2. **Given** 연기로 막힌 계단 앞, **When** 확인 지점에 도착하면, **Then** 연기가 유입되는 계단을 관찰할 수 있으나 사용자는 연기 내부로 이동하지 않는다.
3. **Given** 막힌 계단 앞, **When** ‘이 계단으로 대피한다’를 선택하면, **Then** 진입을 실행하지 않고 이 경로로 대피하기 어려운 이유를 설명하며 재선택을 허용한다.
4. **Given** 막힌 계단을 확인한 사용자, **When** ‘다른 경로를 찾는다’를 선택하면, **Then** 자동으로 정답 계단으로 보내지 않고 직접 돌아서 다른 이동 지점을 이용하게 한다.
5. **Given** 우회 중인 사용자, **When** 이용 가능한 다른 계단에 도착해 대피를 선택하면, **Then** 상황을 완료하고 우회 수행을 기록한다.
6. **Given** 막힌 계단을 방문하지 않은 사용자, **When** 처음부터 이용 가능한 계단을 찾아 대피를 선택하면, **Then** 그대로 완료하며 막힌 계단 방문을 요구하거나 우회 미수행으로 감점하지 않는다.
7. **Given** 아직 선택하지 않은 상태, **When** 이동 지점과 선택지를 보면, **Then** 정답 방향·안전 여부가 버튼 색·문구 차이 또는 이동 표시 유무로 미리 드러나지 않는다. 유도표지와 공간의 연기는 판단 단서로 제공한다.

### User Story 3 - 실제 수행 결과 확인 및 체험 제어 (Priority: P2)

체험자는 자신이 선택한 경로와 우회 여부, 피드백 전후의 판단을 확인하고 재시작하거나 메뉴로 돌아간다. 기존 공용 화면과 설정을 계속 사용한다.

**Why this priority**: 하지 않은 행동을 수행했다고 평가하지 않고, 오답 후 학습과 첫 판단을 구분한다.

**Independent Test**: 직접 완료·우회 완료·오답 후 완료를 각각 실행해 결과를 대조하고, 중단·재개·재시작·기존 콘텐츠 교체를 확인한다.

**Acceptance Scenarios**:

1. **Given** 이용 가능한 계단으로 바로 완료한 실행, **When** 결과를 보면, **Then** ‘대피 경로 선택 완료’가 표시되며 우회를 했다고 표시하지 않는다.
2. **Given** 막힌 계단에서 다른 경로를 선택하고 실제 우회한 실행, **When** 결과를 보면, **Then** ‘대피 경로 선택 완료 · 우회 수행’이 표시된다.
3. **Given** 잘못된 선택 뒤 피드백을 받고 완료한 실행, **When** 결과를 보면, **Then** 완료는 인정하되 첫 선택과 피드백 후 완료를 구분한다.
4. **Given** 이동 또는 선택 중, **When** 중단·재개하면, **Then** 중단 중에는 이동·선택이 실행되지 않고 복귀 후 현재 상황·판단을 이어갈 수 있다.
5. **Given** 자막 끄기 또는 글자 150% 설정, **When** 두 상황을 진행하면, **Then** 필수 조작 안내와 선택 문구는 남으며 글자가 잘리거나 겹치지 않는다.
6. **Given** 체험 종료·재시작·콘텐츠 교체, **When** 새 실행을 진행하면, **Then** 이전 선택·결과가 새 실행에 반영되지 않고 기존 두 콘텐츠도 정상 진행된다.

### Edge Cases

- 이용 가능한 계단에서 ‘다른 경로를 찾는다’를 고르면 강제 완료하지 않고 탐색을 계속할 수 있어야 한다. 이후 같은 확인 지점을 다시 방문할 수 있다.
- 확인 지점을 떠나거나 다른 확인 지점으로 이동하면 이전 대상의 선택은 실행되지 않아야 한다. 현재 판단 대상이 계단인지 엘리베이터인지 명확해야 한다.
- 버튼을 누른 채 이동·화면 전환하거나 빠르게 반복 조작해도 이전 선택이 자동 실행되거나 한 선택이 중복 반영되지 않아야 한다.
- 계단 앞 확인 지점이나 중간 이동 지점에서 연기 속 또는 벽 너머로 순간이동할 수 없어야 한다. 현실의 짧은 걸음·몸 기울임까지 물리적으로 막을 수 있다고 주장하지 않는다.
- 우회 동선에서는 막힌 계단을 통과하지 않고 돌아갈 수 있어야 하며, 최소 하나의 이용 가능한 계단이 유지되어야 한다. 두 경로가 모두 막히는 상황은 이번 범위가 아니다.
- 필요한 안내·선택 또는 이동 경로가 누락돼 진행할 수 없으면 완료를 부여하지 않고 문제 안내와 메뉴 복귀 수단을 제공해야 한다.
- 낮은 자세만으로 막힌 계단 진입을 허용하지 않는다. 연기 높이·색·농도를 실제 안전 여부의 수치 기준으로 가르치지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 사용자는 기존 메뉴에서 세 번째 독립 콘텐츠 ‘안전한 대피 경로 판단’을 선택하고 종료 후 메뉴로 돌아갈 수 있어야 한다. 기존 두 콘텐츠의 진행은 유지해야 한다.
- **FR-002**: 학교 복도 배경에 양 끝의 비상계단, 중앙 부근의 엘리베이터, 교실 문과 피난구 유도등을 제공해야 한다. 두 상황은 같은 학교의 서로 다른 구역으로 구성하고 출발 위치·계단 방향·엘리베이터 위치를 달리해야 한다.
- **FR-003**: 첫 상황은 안내를 받는 경로 확인 연습, 두 번째는 정답을 미리 알려주지 않는 적용 연습이어야 한다. 두 번째에는 연기로 막힌 계단 하나와 연기를 통과하지 않고 접근 가능한 다른 비상계단 하나가 있어야 한다.
- **FR-004**: 복도 이동은 정해진 텔레포트 앵커로 제공해야 한다. 계단·엘리베이터 확인 지점은 진입 전 주변과 대상 상태를 볼 수 있는 복도 쪽에 둬야 한다. 연기로 막힌 계단 내부에는 이동 목적지를 두지 않아야 한다.
- **FR-005**: 확인 지점에서는 현재 대상을 명시하고 계단에는 ‘이 계단으로 대피한다 / 다른 경로를 찾는다’, 엘리베이터에는 ‘이용한다 / 다른 경로를 찾는다’를 제공해야 한다. 대상 상태와 무관하게 같은 종류의 대상에는 같은 선택 문구·표현을 사용해야 한다.
- **FR-006**: 이동 지점 또는 선택지의 표시 유무·정답 색상으로 이용 가능한 계단을 미리 알려주지 않아야 한다. 위험한 계단의 확인 지점도 접근 가능하게 하되 연기 속 진입은 허용하지 않아야 한다.
- **FR-007**: 엘리베이터 이용이나 막힌 계단 진입을 선택하면 이동을 실행하지 않고 선택이 부적절한 이유를 음성과 자막으로 설명한 후 재판단을 허용해야 한다. 오답만으로 체험을 종료하거나 완료 처리하지 않아야 한다.
- **FR-008**: ‘다른 경로를 찾는다’를 선택하면 직접 복도를 이동하며 다른 계단을 찾게 해야 한다. 올바른 계단으로 자동 이동시키거나 두 번째 상황에서 정답 방향을 미리 지시하지 않아야 한다.
- **FR-009**: 이용 가능한 계단의 확인 지점에서 대피를 선택하면 해당 상황의 경로 선택 완료를 인정해야 한다. 막힌 계단 방문, 엘리베이터 방문, 우회 수행을 완료의 필수 조건으로 삼지 않아야 한다.
- **FR-010**: 막힌 계단 확인 지점에서 ‘다른 경로를 찾는다’를 선택한 뒤 다른 계단으로 직접 이동해 완료한 경우에만 우회 수행을 표시해야 한다. 방문만 했거나 이동 전에 종료했다면 우회 완료로 기록하지 않아야 한다.
- **FR-011**: 결과는 ‘대피 경로 선택 완료’와 실제 수행한 경우의 ‘우회 수행’을 구분해야 한다. 우회 미수행으로 감점하지 않고, 첫 선택과 피드백 후 완료를 구분해야 한다.
- **FR-012**: 안내·자막·선택·피드백·설정·중단·결과는 기존 공용 화면을 재사용하고 문구와 동작만 콘텐츠에 맞게 연결해야 한다. 계단·엘리베이터마다 별도 화면을 추가하지 않아야 한다.
- **FR-013**: 체험 안내와 선택지는 기존 하단 가변 높이 패널을 사용해 경로와 연기 관찰을 방해하지 않아야 한다. 빈 행은 접고 내용·동작이 없으면 배경을 숨겨야 한다. 기본/150% 글자와 자막 끄기에서도 필수 조작 안내·선택 문구를 보존해야 한다.
- **FR-014**: 콘텐츠 교체·종료·재시작 시 이전 선택 연결과 결과를 폐기해야 한다. 중단·추적 상실 중에는 공간 이동과 선택을 차단하고 복귀 후 새 조작으로 재개해야 한다. 기존 공용 음량·자막·글자 설정과 재시작·메뉴 복귀를 유지해야 한다.
- **FR-015**: 안내는 계단도 상태를 확인해야 하며 연기로 막힌 경로에 무리하게 진입하지 않는다는 의미를 포함해야 한다. 연기가 보이지 않는 것만으로 현실의 안전을 보장하거나 낮은 자세면 연기 속을 통과해도 된다고 설명하지 않아야 한다.
- **FR-016**: 완료는 ‘대피 경로 선택 연습 완료’로 설명해야 한다. 실제 건물 탈출 완료·생존 보장·실제 화재 대응 능력 검증으로 표현하지 않아야 한다. 두 경로 모두 막힌 경우의 대처는 별도 교육 범위임을 구분해야 한다.

### Key Entities

- **연습 상황**: 학교 구역, 출발 위치, 안내 여부, 경로 배치와 계단 상태를 가진 첫 번째/두 번째 연습.
- **확인 대상**: 계단 또는 엘리베이터와 그 앞의 관찰·선택 위치. 사용자가 판단할 공간 단서와 선택 행동을 제공한다.
- **판단 기록**: 상황과 대상별 첫 선택, 피드백 제공 여부, 이후 선택. 사용자가 관찰하거나 이해했음을 시선·방문만으로 단정하지 않는다.
- **체험 결과**: 상황별 경로 선택 완료 여부, 실제 우회 수행 여부, 첫 판단과 피드백 후 완료의 구분. 실제 탈출 능력 점수가 아니다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 두 상황에서 각각 이용 가능한 계단을 선택해 완료할 수 있고, 두 번째 상황의 직접 완료·우회 완료·잘못된 선택 후 완료 경로가 모두 끝까지 진행된다.
- **SC-002**: 엘리베이터 이용·막힌 계단 진입을 시도하는 모든 인수 시나리오에서 위험 공간으로 이동한 사례가 0건이고, 이유 안내와 재선택이 모두 제공된다.
- **SC-003**: 막힌 계단 미방문 직접 완료의 방문 강제·감점·우회 허위 표시가 0건이다. 실제 우회 완료에는 우회 수행이 표시되고, 오답 후 완료를 첫 시도 정답으로 표시하는 사례가 0건이다.
- **SC-004**: 두 상황은 출발 위치·계단 방향·엘리베이터 위치의 3개 배치 항목이 모두 다르며, 두 번째 상황의 선택 전 정답 표시·정답 방향 안내가 0건이다. 우회 경로에 연기 통과가 필요한 구간이 0곳이다.
- **SC-005**: 기본 글자·150% 글자·자막 끄기에서 두 상황과 피드백·결과의 필수 문구 누락·잘림·겹침이 0건이고, 확인 지점에서 판단 대상과 경로 상태를 함께 볼 수 있다.
- **SC-006**: 중단·재개·재시작·메뉴 복귀·세 콘텐츠 왕복에서 이전 판단의 오작동·중복 실행·중단 중 이동이 0건이며 기존 두 콘텐츠가 끝까지 진행된다.
- **SC-007**: 대본과 결과 문구 전수 검토에서 실제 탈출 완료·연기 없는 외관만으로 안전 보장·우회 미수행자의 우회 능력 검증 주장이 0건이다. 계단 상태 확인과 막힌 경로 회피의 교육 의미가 모두 포함된다.

## Assumptions

### 사용자 확정 사항

- 세 번째 콘텐츠 주제, 학교 복도 배경, 두 개의 다른 구역에서 안내 연습 후 적용 연습, 막힌 계단에서 다른 계단으로 우회하는 범위는 대화에서 확정했다.
- 앵커 이동과 확인 지점 선택지, 엘리베이터 선택 가능 및 탑승 차단, 위험한 선택의 피드백·재시도, 직접 완료 인정과 우회 미수행 감점 금지, 실제 수행만 결과에 표시하는 기준을 확정했다.
- 기존 공용 UI 재사용은 프로젝트의 기존 확정 원칙이다. 새 콘텐츠 전용 Canvas는 만들지 않고 공용 Canvas 1개·공용 안내 재생기 1개 구조를 유지한다. 이는 기술 선택의 새 제안이 아니라 기존 통합 제약이다.

### 명세 작성에 사용한 기본값 — 사용자 미확정

- 첫 상황 완료 후 사용자가 다음 진행을 선택해 두 번째 상황으로 넘어가며, 최종 결과에 두 상황을 구분해 표시하는 흐름을 기본값으로 둔다.
- 완료 지점은 이용 가능한 계단 앞의 대피 선택이다. 실제 계단 전체 하강·건물 밖 이동은 추가하지 않는다. 선택 이후 연출과 정확한 대본·공간 치수·앵커 수는 후속 계획에서 정하며 교육 범위를 늘리지 않는다.
- 시간 제한·점수·생존 시간·흡입량 계산·새 자세 인식은 도입하지 않는다. 두 경로 모두 막힘, 문 열기·닫기 실습, 119 통화, 피난시설 사용, 초기 진화는 이번 명세의 범위에서 제외한다.
- 기존 한국어 안내·자막 제공 방식을 따른다. 판단 기록은 현재 실행 결과 표시용으로만 사용하고 계정·개인정보·장기 학습 이력 저장은 추가하지 않는다.
- 배치는 두 개의 고정된 학교 구역을 기본값으로 두며 무작위 맵 생성은 요구하지 않는다. 배치 변경만으로 실제 판단 능력이 검증되었다고 보지 않는다.

### 의존성과 검증 한계

- 기존 공용 시스템·단일 씬 통합·텔레포트 입력·중단 처리와 새 콘텐츠 제작 지침에 의존한다. 구현 자산은 `Assets/_02LWS`에 두고 제출용 통합 프로젝트로의 내보내기·가져오기 조건을 보존한다.
- UI 연결과 회귀 확인은 [새 콘텐츠 제작 기준](../../Assets/_02LWS/Documentation/ContentAuthoring.md)을 따른다. 기존 화면의 문구·동작 연결을 사용하며 새 콘텐츠 전용 패널로 우회하지 않는다.
- 구현 검증에는 현재 헌장 v1.3.0의 실제 실행 MP4(1920×1080 이상·30fps 이상·게임 소리 포함·다른 앱 소리와 마이크 제외) 및 실제 화면·소리 재생 확인을 적용한다. 불가 시 사유·대체 자료·미검증을 기록하고 `Artifacts/Validation/VisualEvidence/` 아래 Git 비추적으로 보관한다. 문서만 작성하는 이번 작업에는 실행 녹화가 필요하지 않다.
- Editor 검증과 실제 Quest 검증을 분리하고, 수신 프로젝트 가져오기·실기기 가독성·조작 편안함·성능·학습 효과를 실행 없이 합격으로 처리하지 않는다.
- 교육 근거는 [국민재난안전포털 화재 행동요령](https://old.safekorea.go.kr/idsiSFK/neo/main_m/sot/fire.html)(2026-11-13 확인)의 계단 이용·엘리베이터 회피·상황에 따른 대피 판단을 참고한다. 같은 페이지의 아파트 전용 피난시설·실내 대기 조건을 학교의 일반 규칙으로 옮기지 않는다. 두 학교 구역의 배치·선택지는 본 앱의 연습 설계이며 공식 매뉴얼의 재현이라고 주장하지 않는다.
