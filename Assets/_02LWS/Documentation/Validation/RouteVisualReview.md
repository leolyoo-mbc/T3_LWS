# 학교 복도 A/B 외관 검토

상태: 사용자 승인 대기. 기존 두 콘텐츠의 외관 수정은 이번 범위가 아니다.

FR-017 구현: 교실 문과 창문의 반복, 문과 창의 깊이, 문틀과 손잡이, 창대와 세로 프레임, 천장 패널과 조명, 계단참/단차/난간, 엘리베이터 문과 두꺼운 테두리를 구성했다. A 직선과 B 꺾인 복도는 동일한 재질과 구조 요소를 사용한다.

실행 확인 중 시작 방향, 표지의 뒤집힘, 천장과 벽 사이 틈, 바닥 재질 비례를 수정했다. 최종 동일 위치 실행 화면을 제공한 뒤 사용자 검토 결과와 수정 요청을 여기에 기록한다. 자동 기능 검사 통과는 SC-008 사용자 승인과 다르다.

계단 확인 지점은 실제 실행에서 결과 UI와 계단 표지가 겹쳐 입구에서 3 m인 제작값으로 조정했다. 실제 화재의 안전 거리 기준이 아니다. 도착 반경 0.65 m, 앵커 간 최소 2 m는 유지한다. B 모서리의 벽/바닥/천장 연결과 문 위 틈도 보완했다.
