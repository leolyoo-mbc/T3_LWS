# 경로 판단 신규 음원 검수

상태: 사용자 청취 승인 대기. 기존 콘텐츠의 F1 승인은 이 7개 신규 cue를 포함하지 않는다.

실제 파일: `Audio/Voice/EvacuationRoute/ready.wav`, `intro-a.wav`, `intro-b.wav`, `elevator.wav`, `smoke.wav`, `complete-a.wav`, `completion.wav`.

VoiceManifest.json의 대본, PCM 16-bit / 44100 Hz, 실제 길이와 SHA-256을 대조한다. 발음, 끊김, 억양, 차분한 전달과 자막 일치를 실제 재생해 검수한 뒤 사용자 승인 또는 수정 요청을 기록한다. 파일 생성 성공과 비무음 신호는 청취 승인이 아니다.

재생 파일: [준비](E:/projects/T3_LWS/Assets/_02LWS/Audio/Voice/EvacuationRoute/ready.wav), [A 확인 방법](E:/projects/T3_LWS/Assets/_02LWS/Audio/Voice/EvacuationRoute/intro-a.wav), [B 도입](E:/projects/T3_LWS/Assets/_02LWS/Audio/Voice/EvacuationRoute/intro-b.wav), [엘리베이터 피드백](E:/projects/T3_LWS/Assets/_02LWS/Audio/Voice/EvacuationRoute/elevator.wav), [막힌 계단 피드백](E:/projects/T3_LWS/Assets/_02LWS/Audio/Voice/EvacuationRoute/smoke.wav), [A 완료](E:/projects/T3_LWS/Assets/_02LWS/Audio/Voice/EvacuationRoute/complete-a.wav), [최종 완료](E:/projects/T3_LWS/Assets/_02LWS/Audio/Voice/EvacuationRoute/completion.wav). 이 경로는 개발 PC의 실제 WAV이며, 납품 폴더에서는 위 상대 위치를 사용한다.
