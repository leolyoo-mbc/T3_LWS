# 안전한 대피 경로 판단 안내 대본

AI 합성 음성: Supertonic 2, F1, ko, speed 0.95, 16 steps. 신규 음원 청취 승인은 대기 상태다.

| ID | 대본 |
|---|---|
| ready | 학교 복도에서 대피 경로를 선택하는 연습입니다. 준비가 되면 준비 완료를 선택하세요. 불편하면 언제든 메뉴에서 중단할 수 있습니다. |
| intro-a | 주변의 유도표지와 계단 상태를 살펴보세요. 바닥의 이동 지점을 가리켜 순간이동하고, 입구 앞 확인 지점에서는 주변을 살핀 뒤 행동을 선택하세요. |
| intro-b | 같은 학교의 다른 구역입니다. 주변의 표지와 경로 상태를 살펴보고, 이용할 대피 경로를 직접 선택해 보세요. |
| elevator | 화재 때는 정전이나 고장으로 갇히거나 연기에 노출될 수 있어 엘리베이터를 이용하지 않습니다. 다른 경로를 찾아보세요. |
| smoke | 연기로 막힌 계단에 무리하게 들어가면 위험합니다. 낮은 자세만으로 통과할 수 있는 것은 아닙니다. 이 연습에서는 다른 경로를 찾아보세요. |
| complete-a | 첫 번째 대피 경로 선택 연습을 마쳤습니다. 계단도 주변 상태를 확인해야 합니다. 다음 연습에서는 다른 구역에서 판단해 보세요. |
| completion | 두 상황의 대피 경로 선택 연습을 마쳤습니다. 연기가 보이지 않는 것만으로 실제 안전을 보장하지는 않습니다. 실제 건물 탈출을 완료한 것은 아닙니다. 모든 경로가 막힌 경우의 대처는 별도 교육에서 다룹니다. |

교육 근거는 명세가 인용한 [국민재난안전포털 화재 행동요령](https://old.safekorea.go.kr/idsiSFK/neo/main_m/sot/fire.html)과 [승강기 안전사고 행동요령](https://old.safekorea.go.kr/idsiSFK/neo/main_m/lit/elevator.html)을 2026-11-13에 대조했다. 정답 방향 사전 지시, 연기 수치의 안전 기준화, 실제 탈출 능력 판정은 포함하지 않는다.

공식 내용과의 대조: 화재 문서의 대피 방법 결정/계단 이용/엘리베이터 회피와, 승강기 문서의 정전 정지/화재 시 이용 금지 항목을 반영했다. 정전/고장/승강로 화재의 위험 이유는 이 항목들을 교육용으로 요약한 설명이며 공식 문구의 인용이 아니다. 계단의 연기 여부를 판단하는 두 학교 구역과 다른 계단으로의 우회는 앱의 연습 설계다. 아파트 전용 피난시설/실내 대기 조건을 학교 일반 규칙으로 옮기지 않았다. 새로운 거리, 자세 또는 연기 농도를 실제 안전 기준으로 설명하지 않는다.
